# CAD Translate Pro

Translate editable DWG engineering drawings while preserving native geometry, technical notation, and drawing structure. The project supports target-language replacement and a bilingual mode that retains the source text.

The root [`SKILL.md`](SKILL.md) defines the workflow. The assistant translates drawing text in context; project tools handle extraction, native DWG editing, layout checks, and verification after saving. See [`references/`](references/) for the native DWG contracts and terminology guidance.

The workflow checks drawing scope, visible text, engineering symbols and numbers, and the saved DWG before delivery. Final deliverables are editable DWG files.
