# 原生 DWG 经验在双语模式中的应用

本规则取自用户提供的 cad-translate-dwg 技能，并按双语保留原文的要求适配。执行前识别当前图纸的专业、实际字体、块实例和语义组；这些检查由模型和原生工具完成，无需用户逐条加工。

## 先组成完整含义，再翻译

散落文字、被拆成多实体的句子和表头，先依据基线、旋转、相近字号、所属栏和上下文组成完整语义单元。单字符标题不能逐字译成多个英文词。表格边界、跨栏间隔和不同注释区是分组边界，禁止把邻格或邻行内容拼成一句。

保留全部来源 recordId/handle 与译文的对应关系；多个来源可以对应一个新增译文对象，覆盖核验不能只比较实体数量。原文实体不删除、不替换。现有 termMemberIds 只覆盖其已验证的字符组，不代表所有句子都已重建；遇到更复杂碎片需检查当前原生清单和图面，显式成组后再写回。已有双语内容先应用 bilingual-workflow 的跳过规则。

## 可读的分组排版

段落先保留完整含义、编号和阅读顺序，利用既有允许区域换行，再调整字号。同一译文块统一字体、字号、行距、编号与缩进，不采用每一行独立缩放。保留现行双语的同宽块、位置选择、表格目标列和整表复制规则；单语技能的原位覆盖规则不应用于双语。

旋转文字在局部坐标系内计算允许区域，并通过完整嵌套块变换核验实际实例。世界坐标包围盒的窄边不能直接当作旋转文字的可用行宽。读取 MText 的实际高度并检查保存后的换行；优先换行、组排版和邻近留白，再降低字号。运行时紧急缩小阈值不是可读性证明，明显变小的译文必须在原生视图的合理比例下核验，无法读清就局部修复。

新增 MText 先 SetDatabaseDefaults，再 SetPropertiesFrom 代表源实体，之后明确设置目标字体、旋转、附件点、宽度与字号。保留图层、颜色、线型等实体属性，避免修改共享文字样式影响原文或工程符号。

## 字体与工程符号

检查源字体、大字体和真实显示。普通英文可选经核验的 Latin 字体；中文和其他目标语言需有完整字形覆盖。保留专用 SHX 字形，不能把钢筋等级一律换成直径符号。

TEXT 到新增 MText 的转换需特别核验旧 %%nnn 代码。仅在对应字体和显示已证明含义时，采用 [原生符号处理](../formats/dwg/replace/references/native-dwg.md) 的条件转换（TSSD %%130–134、上标 %%1402%%141 等）；禁止把字体专用映射用于其他字体或全局删除百分号控制码。原对象已是 MText 时同样查看实际显示。符号无法确认时记录明确阻塞，原文字保持不变。

## 独立保存后核验与时间控制

所有 CAD 会话只打开工作副本，包括导出、局部修复、渲染和最终核验。原始文件只进行复制和哈希读取；交付前重新检查源哈希。等待写回进程退出后，从最终候选的新副本重新提取，核对原文保留、目标覆盖、数值/符号、字体、实例变换和非文字实际几何；不能以写回内存内容证明保存成功。

核验每张图的全图和文字密集区域，包括标题、段落、表格、旋转文字和工程符号。用 DWG 原生视图或直接原生 PNG，内部截图不作为额外交付。残留源语言是双语的预期结果，检查缺失/重复目标译文，而不是要求中文归零。图片、轮廓文字、外参和代理覆盖缺口必须明确。

复用本次任务内已验证的语义和术语；批量提取、写回与核验，局部缺陷集中一次修复后先看受影响区域，再做最终整体核验。只有新变化或失败才触发额外重跑。新测试必须建立新映射与新工作副本。交付继续使用 bilingual-final 和绑定最终哈希的 bilingual-visual-review，audit-summary 必须确认 deliveryReady=true。
