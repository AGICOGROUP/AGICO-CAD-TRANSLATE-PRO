# Bilingual pipeline

Preserve original entities and add target-only MText nearby. Never rewrite the Chinese/English original to hold both languages. Export model space and every layout, including all recursively referenced block definitions. Keep unused block-library definitions unchanged; record exclusions in `bilingual-scope.json`. Do not spend translation or fitting time on dormant definitions that have no placed instances. Existing equivalent inline text or a uniquely matched nearby translation is reused; codes such as HCQ2000 are not evidence of bilingual coverage. Title-block equivalence uses a bounded vocabulary (for example Design / Designed by), never fuzzy matching of equipment qualifiers, codes or quantities.

Identify the source reading block even when numbered clauses, indentation, headings or different line heights split it into many entities. Placement measures the target text's real unwrapped MText width at each candidate scale. XY nearby labels first try source-height and 70%-height normal-width text at at most 16 adjacent positions. If those fail, search bounded obstacle-edge pockets within 0.8 source text heights, then within 2 heights, testing normal/modestly condensed width, controlled wrapping and 70–35% height before smaller fallback sizes. Retain essential side/edge anchors even in dense drawings and filter known geometry collisions before truncating the candidate shortlist. A bounded grid fallback within 4 heights covers irregular gaps missed by edge anchors; only then allow the existing wider search. Measure proximity edge-to-edge, not between centers: a long translation immediately below its original is still near. Prefer close readable wrapping over a remote single line; smaller fallback text requires actual readability review, not approval from distance alone. Table copies and grouped explanation blocks retain their separate whole-group placement. For rotated text, generate positions using the rotated footprint and compensate the insertion anchor; evaluate wrap widths along the text direction. Wrapping is conditional, never globally disabled or applied merely because the Chinese box is narrow. New target bounds combine native extents and padded font metrics: neither alone proves clearance. All fallbacks use the same containment, boundary and protected-geometry checks; they cannot bypass checks to reduce the unresolved count. This does not widen cells, move originals or trigger another whole-drawing run. Small but readable text remains a visual judgement, not a new universal minimum-height gate. Non-XY planes and nested block instances require specific placed-world review; a copied rotation is not proof of correct 3D placement.

When model/paper space and inserted block definitions both contain text, project occupied bounds through every direct/nested block-instance transform before choosing a position. Update those projected bounds after every addition so text that is collision-free in separate local definitions cannot overlap in the final visible layout. Ordinary-label placement also projects other definitions' captured boundary segments into its search regions once, keeping model/paper roots separate. A closer translation must not cross a road, wall or grid line belonging to another block. This segment check is not full 3D/proxy/solid clearance; visually inspect the placed world view, and do not treat a lower distance-warning count alone as a better result.

During review, specifically compare short labels such as flow directions, cabinet names and drawing titles. Ordinary added labels more than two source text heights from their originals are flagged as `distant-bilingual-label` in the saved-layout review; this is an association-review pointer, not a hard distance gate. Check that a remote label cannot be mistaken for a neighboring source and correct it locally when a closer readable position exists. Table copies and grouped explanation blocks are exempt from this individual-label warning. Prefer single-line short labels when horizontal whitespace permits. A readable unnecessary wrap may be disclosed as a minor warning instead of forcing another job; fix it when a cheap local adjustment is available. Long equipment names may wrap when the available region genuinely cannot hold the measured single-line form safely. The bilingual branch independently accepts `passed_with_warnings` visual reviews for cosmetic issues only; missing additions, altered originals, incorrect associations and serious obstruction remain blocking.
