# Replacement pipeline

Replace original text with the requested target language. Preserve geometry, codes, units, layer/style hierarchy and unrelated content. Fit changed text within its original cell or allowed region; full translations should fit by wrapping and width adjustment before shrinking.

```powershell
python scripts/cad_translate.py export --source "source.dwg" --job "jobs/replace-001" --output-mode replace --source-language zh-CN --target-language en
python scripts/cad_translate.py prepare-translations --job "jobs/replace-001"
# Consult references/cement-industry-glossary.md for current worklist terms (SKILL.md).
# Translate each worklist part to exchange/translated-batches/part-0001.jsonl, etc.; review term consistency before assembly.
python scripts/cad_translate.py assemble-translations --job "jobs/replace-001" --translated "jobs/replace-001/exchange/translated-batches"
python scripts/cad_translate.py import --job "jobs/replace-001" --translations "jobs/replace-001/exchange/translations.output.jsonl"
python scripts/cad_translate.py audit-summary --job "jobs/replace-001"
# Even out the text size inside each note column before the visual review: the fitter sizes
# every line from its own box, so one paragraph can hold 1.0-scale and 0.25-scale lines.
python scripts/harmonize_heights.py --job "jobs/replace-001" --apply
```

For English→Chinese use `--source-language en --target-language zh-CN`. Translation JSONL is target-only in both directions. IDs absent from the deduplicated worklist are restored by assembly; never fabricate them.

The native replacement pipeline captures topology once and applies the replacement fitter. Its saved-output audit refines possible curve/dimension collisions against actual curve outlines; unsupported geometry remains explicitly uncertain, not clear whitespace. If confirmed high-risk text/geometry contacts remain, one bounded batch attempts nearby text-only placement using the same translations, then reopens and re-audits once. The batch repairs block-definition content in definition-local coordinates (one fix covers every placed instance), keeps each text inside its own cell/title-block/note-column, and searches a 48-cell distance-ordered grid that snaps flush to occupied text edges while stepping height down to the fitter's 0.25 floor and width factor down to 0.2; unmeasurable nested references farther than one text height from the proposal do not veto it. Adopt corrections only if high-risk count decreases with no new high-risk identities (identity = record pair + code + instance path, never the Detail string); otherwise retain the prior candidate. `replace-local-correction.json` `diagnostics` reports the failing stage for every record that could not be placed. Attributes, rotated text and unresolved contacts remain for review; when a source line is split into single-character label fragments beside fixed values (页A10详B style), author the translation compactly (`Pg.`, `DTL`) instead of relying on placement repair. This retry belongs only to replacement; bilingual placement and gates are independent. The pipeline then verifies saved content, runs eligible English prose composition, reopens the output and checks non-text structure. Chinese output retains the verified per-entity fitting and never uses legacy English-preferring composition. Final text is extracted within the same CAD process. Python checks replacement-only language integrity and routes estimated overflow to visual assessment; there is no separate unconditional compose/export process.

Relevant artifacts: `replace-layout-audit.json`, `replace-local-correction.json` (when a local retry is attempted), `logical-flow-report.json`, `replace-structure.json`, `replace-native-check.json`, `replace-language.json`, `replace-final.json`. Content/structure/coverage failures remain blocking. Layout collision findings and estimated segment overflow retain a complete candidate instead of discarding it. The record IDs and overflow count in `replace-final.json` guide the single final [visual review](visual-audit.md), not a separate approval checklist. A hash-bound `replace-visual-review.json` is needed to finish delivery. Review may accept harmless contacts or minor cosmetic issues, but not material obstruction or lost engineering meaning. Neutral punctuation/full-width brackets in otherwise translated English are not untranslated Chinese and do not fail the language check.

## Fast, complete translation

Replacement grouping ignores presentation-only differences (font, height, width and alignment), while retaining exact source, protected values, object type, role, layer and attribute tag. CAD still fits every entity separately. Translate the full term once; inspect the included `protectedTokens` and `contextVariants`. Bilingual grouping is unchanged.

Fix all rows in `artifacts/translation-marker-repairs.jsonl` together when assembly reports marker errors. Pre-CAD assembly failures may be corrected in the same job: export data is unchanged and no candidate exists. Preserve completed good batches. For a native failure, use the same job’s [recovery workflow](recovery-workflow.md): inspect the retained candidate or retry only the missing stage. A fresh job is needed only when source/mode/language or the candidate’s translation content changes. Do not regenerate good translations.

Read `replace-semantic-review.json` before import. It flags possible loss of company names, storage equipment, quicklime qualifiers and unexplained acronyms. Resolve against the source and glossary; these heuristics are advisory and cannot establish complete translation accuracy. Do not use automatic layout success as semantic approval.

Preserve existing text anchors, rotation, layer, color and style as far as target text permits. Use the complete approved translation as the content authority through fitting and composition. Model codes (such as MDPX150), capacities, units and font-control names do not establish that a Chinese label is already bilingual. If post-composition text has lost words, restore the full approved text with its protected formatting to every affected occurrence, using the layout audit's handle mapping; do not reconstruct it by removing Chinese from the source or accept a surviving model number as a translation.

For a local overlap or unsuitable wrap, keep the rest of the drawing unchanged and adjust the affected text in a candidate copy. First widen the text box toward actual nearby whitespace while retaining its anchor. Keep one line when it fits; otherwise allow controlled wrapping. If that still crosses equipment, neighboring text or a frame, move the complete label or note a short distance above, below or beside its source location within the same view, keeping its association clear. Confine table/title-block text to its cell. Preserve rotation, layer, color and style; reduce height only after width, wrapping and a nearby safe placement have been considered. Never use drawing-specific coordinates as a general placement rule or move geometry to make room. `replace-readability-review.json` selects labels reduced below 65% of source height for close inspection; inspect these labels at readable scale rather than assuming failure or success from the ratio.

Use `correct --job --corrections` from the [recovery workflow](recovery-workflow.md) to batch supported layout edits into one native edit/save pass, preserving the original DWG version. Reuse the approved translations; do not rerun translation or redevelop the plugin for routine fitting. Inspect the final post-composition text, not just the pre-composition layout audit. Verify corrected content against the full restored translations and confirm unchanged non-text/table structure; when composition merged entities, follow its reported membership instead of assuming one old handle per output. Re-render corrected regions plus a final overview, then bind the replacement final/visual receipts to that exact verified file hash. Never just update receipt hashes to bypass a failed check. Resolve semantic and readability findings before delivery; do not shorten technical meaning to clear a collision.

## Monolingual replace hardening (merged)

These rules extend the replacement pipeline for single-language output and override the generic fitting notes above where they conflict. Bilingual mode keeps its own placement and gates.

**Extraction scope.** Walk the model space, every paper space and every non-xref `BlockTableRecord` (including unreferenced definitions); cover `DBText`, `MText`, `AttributeDefinition`, `AttributeReference`, `MLeader` (its MText copy or block-attribute content, written back to `MLeader.MText`), `Dimension` (non-empty `DimensionText` only; never touch auto-measured values or `<>` placeholders) and `Table` (per-cell content items with zero-based `row`,`column`,`contentIndex`; do not treat block content or fields as plain strings). The shipped native adapters currently implement `DBText`, `MText`, `AttributeDefinition`/`AttributeReference` and `Dimension`; `MLeader` and `Table` are contract targets. Until their dedicated readers/writers exist and are regression-verified, any `MLeader`/`Table` content must be listed in `coverageIssues` and disclosed — never silently skipped nor counted as covered, and never double-counted by also reading an MLeader's child MText as a standalone record. Ordinary `Leader` annotations are resolved through their reference to the text entity. Decode `\U+XXXX`; keep MText control strings separate from display text and translate only visible content. Block names, layer names and attribute tags are internal identifiers: never count them as residue or rename them casually. Record, per record, handle, kind, slot, raw, visible text, owning block/space, attribute owner/tag, layer, font/big-font, insertion/alignment point, rotation, height, width, bounding box and, for nested visible instances, the full transform. Also snapshot non-text geometry (line endpoints, circle center/radius, arc angles, polyline vertices/bulge, block insert/scale/rotation) so geometry equality is proven by parameters, not bounding boxes alone.

**Mapping contract.** Each edit carries `handle`, `kind`, `slot` (identical to extraction; tables also carry integer zero-based indices for cross-check), `expectedRaw` (byte-identical to the source `raw`, never the decoded display text), `action` (`replace` / `retain` with reason / `reflow-member` referencing a verified group), non-empty `target` for `replace`, a `layoutPlan` (strategy, allowed region, coordinate system, font/size, verification state), `protectedValues` (source/target pairs for numbers, symbols, codes, fields) and `verificationIssues`. Reflow groups list every source handle, owning block, the representative entity whose attributes are inherited, the original note rectangle, coordinate system/rotation, target content, font, size and layout strategy; programs execute those explicit parameters, never coordinates copied from another drawing. Before writing, re-check the current input fingerprint and every `expectedRaw`; a changed input or mismatched source aborts that record (it is never force-written from a stale mapping). Missing index declarations are re-extracted, never guessed.

**Write-back safety.** Open for write with `transaction.GetObject(id, OpenMode.ForWrite, false, true)` (force open on locked layer) instead of unlock/restore; `UpgradeOpen()` alone can raise `eOnLockedLayer`. Throw on `expectedRaw` mismatch; do not catch-and-continue and call it success. After changing a `DBText` style/width call `AdjustAlignment(db)` and keep the original alignment anchor. New `MText` must `SetDatabaseDefaults(db)` then `SetPropertiesFrom(sourceEntity)` before placement, otherwise nested-block color/layer revert to defaults; keep rotation, position and attachment point; never mutate a shared style to fit translated text (create a separate target style when needed). All writes happen in one controlled transaction; any unhandled failure rolls back and no partial candidate is presented as complete.

**Engineering symbols.** `%%130`–`%%134` may be converted to `\U+0082`–`\U+0086` only when the corresponding TSSD/SHX font is confirmed and the native display is checked; this is not a universal rebar-symbol table. A confirmed `%%1402%%141` (superscript 2) becomes MText-native `{\H0.7x;\S2^;}` (and `%%1403%%141` likewise); `%%%` becomes `%` only when the source truly displays one percent sign. Diameter, plus-minus, degree, super/subscripts and field structures are preserved. This check applies even when the source object is already `MText`: inspect the original display and recorded formatting first; if a code's meaning cannot be confirmed, keep the original code, record a `symbol_unverified` blocking issue, and never count that record as passing or guess it into a plain number/diameter symbol.

**Space and fit.** Measure available space in the text's local coordinate system. For rotation θ with axis-aligned box w,h, `abs(cosθ)*w + abs(sinθ)*h` is only an axial-projection estimate; for arbitrary angles use the true region's inverse transform, and never squeeze 90° text using the world-coordinate narrow side. Prefer concise accurate target text, wrapping and paragraph reflow; adjust width factor/height only afterwards. Set the readable floor from the plot scale (or, when unknown, from source height and native-view legibility); the fitter's 0.25 emergency floor is a bound, not a target — any text fitted at or below the readable floor must be surfaced in `replace-readability-review.json` for close inspection, never silently accepted. For `MText`, set the allowed width then read `ActualHeight` and iterate within the readable range. Keep one note column's paragraph font size, line spacing, numbering and indent consistent; tables keep row/column boundaries, merges, lines and engineering data; notes must not cross columns or cover dimensions, leaders, rebar or geometry.

**Post-save acceptance.** Verify from a fresh working copy of the saved candidate in a new session; in-memory modified content is never evidence of a successful save. Status is a state machine: `failed` → `written-awaiting-verification` → `verified`; file existence or a zero exit code never upgrades it. The acceptance list covers source/target text coverage, per-type write failures, drawing scope, non-target-language residue, engineering values/symbols, fields, font dependencies, non-text geometry change, every deliberate scope change and the original source SHA-256. Residue checks target all visible non-target languages (not only CJK); formulas, codes and project identifiers are retained by context. Compare against the source DWG sheet by sheet, full view plus dense areas (titles, technical notes, tables, rebar details) via native view or native PNG; PNG comes from a native plot device (e.g. `PublishToWeb PNG.pc3` queried through `PlotSettingsValidator` with independent `PlotSettings`/`PlotInfo.OverrideSettings`), never PDF conversion. Text correctness and visual correctness are separate acceptances. When embedded pictures, outline (vectorized) text or proxy content were not extracted, the report must say so and must not claim a whole-drawing no-omission result; `coverageIssues` may never be faked empty.

**Delivery boundary.** The final attachment is the `.dwg` only; JSON, logs, builds, screenshots and status files stay in the work directory. Do not ask the user to hand-layout or confirm translations line by line. Reuse confirmed terminology and source mappings within the task; merge duplicate extractions and batch writes; test tasks start from a fresh working copy and never reuse historical translations. Do not promise that one drawing's sheet count, entity count or zero-residue statistic applies to the next.
