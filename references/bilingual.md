# 新原生 DWG 双语流程

本流程从 cad-translate-dwg 的完整提取、语义重建、原生写回和保存后检查扩展。共用 native-dwg.md 与 data-contracts.md；新增契约见 bilingual-contract.md。源文保留，目标文新增；当前模型直接翻译，程序完成确定性的排版、写回和核验。

## 提取和语义配对

1. 新任务创建独立工作副本，记录原始源 SHA-256。测试不得使用历史译文、图面、候选或验收凭据。
2. 按基础契约遍历模型、布局、所有非外参块及实例属性。提取表格每个文本内容项、MLeader 和尺寸覆盖；外参、字段、图片、代理与轮廓文字的缺口必须明确记录。缺口未解决不能交付完整双语图。
3. 先重建同一栏、单元格、段落或标题的完整语义，再翻译。每个原始 `handle + slot` 都有 retain 动作。每个待译语义组只归属一个 addition，不分别翻译单字符碎片，也不丢失数字字段。
4. 按完整含义判定已有双语：记录实际对应目标实体、完整性和语义依据。一个英文单词、型号、单位、公司标识不能证明整段已翻译。图签或表头已有双语时仍逐项核对中文填写值；未译的中文值需添加目标，不能整块跳过。
5. 中文到英文按语境查 cement-industry-glossary.md；其他目标语言用其澄清专业概念，再生成用户指定语言。

## 布局

在原对象所属块坐标系中计划目标，记录旋转、允许区域和实例变换。原文位置、内容、字号、样式以及原工程几何不变。

- **散点标签**：首选原文下方，其次上方、右侧、左侧的邻近留白；目标与原文形成清晰局部配对。不得为了通过检查移到其他构件旁。允许跨普通线条，但不能覆盖其他文字、尺寸数字或破坏关键工程表达。
- **段落**：每个完整原段落对应一个目标块，首选原文正下方，同宽调整高度；不足时找同一视图中邻近留白。优先不覆盖工程线条，不把不同原段落合并成远处的一个共享译文区。若跨图框，必须记录实际可打印范围并在交付时说明。
- **表格**：先按行号匹配已有源/目标列，目标独立 MText 只能放在对应行的原有空白目标区域；已完整译文保留。没有目标列时，先在原单元格里安排明确上下分区，保留源文且保证文字间隔。单元格容不下时，在旁边空白区域新增带原行号的目标文字表，列宽及行对齐依据源表；无需复制网格。不能把目标放在邻行，不能把零散后缀挤在源文后面。若确需新增网格，用明确计划和新增几何收据核验，不能修改原网格。
- **图签/签名**：译文留在对应单元格内；原文旋转时，可以在该单元格的空白区域使用水平英文，记录配对。没有可读空间时重新选择排版，不缩成微小字来强行通过。

优先换行、邻近空间和统一段落样式，再有限调整宽度或字号。字号底限依据出图比例和原生可读性；未知比例时通常从原文高度的 0.65 倍起评估，不能把数值底限当作验收。涉及钢筋专用字形的目标保留经验证的 SHX 表达；无法显示时，依据原图明确的等级图例使用完整等级及直径文字，不能把所有等级一律换成直径。

## 原生写回

使用一个受控事务逐条比对 expectedRaw。所有 edits 是 retain；只新增 additions 的 独立 MText（也可叠放在已确认空白的单元格区域，不修改 Table 内容项）。新对象先 SetDatabaseDefaults，再 SetPropertiesFrom 代表源对象，保持图层、颜色等属性；需要英文样式时创建独立样式，不能改共享源样式。

对每个新增对象记录 addition id、sourceKeys、实际目标 handle/slot；使用按 id 记录的对象绑定，禁止同一组重复添加。放置前检查目标单元格区域确实空白，不能覆盖已有目标或字段。锁层使用 forceOpenOnLockedLayer，不捕获失败后继续称为成功。

目标新增前检查源/目标文本占用；保存到独立 candidate.dwg 后结束 CAD 进程，在新会话里打开新的保存后副本重新提取。实际保存后的包围盒、字高、源文与目标关联才是核验依据。

## 验收与修正

调用 job-tools.md 的 validate 和 verify；同时逐张检查源/候选全图、说明栏、表格、旋转标签与图签的原生截图。检查目标完整、数字单位和工程符号正确、原文未变、目标不遮挡文字、字号可读及局部配对清晰。原文中文保留不属于漏译；检查的是需要译文的源记录是否全部有目标或确实已有完整对应。

出现文字重叠、字号不足或对应不明时，在本任务中合并一次局部修正，保留已完成译文；修正后重新保存、重新提取，并检查受影响区域。没有安全空间时继续解决具体区域，不能静默跳过或交付“完成版”。

再次处理已有双语输出时，重新提取当前输入、重新确认现有配对，不从历史任务导入译文。已完整双语源组只 retain；新增计数应为 0，原文/已有译文均保持不变。

最终仅交付带递增版本号的 DWG。完整验收未通过时，仅可明确标为待修正草稿，不称为完成。
