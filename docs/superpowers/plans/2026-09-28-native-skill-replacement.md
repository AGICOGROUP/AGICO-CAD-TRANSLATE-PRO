# 原生 CAD 技能替换实施计划

用户已指定：以 cad-translate-dwg.zip 替换旧 PRO，清空旧双语，再从新技能基础重建双语。

## 设计
- 保留现有技能安装位置和界面名称，入口切换到新原生 DWG 流程。
- 原包 native-dwg.md、data-contracts.md 原文作为共用基础；单语正文保持原包要求。
- 旧代码、旧 DLL、旧参考和旧测试退出活动树。历史 jobs/work/outputs 不作为新任务输入。
- 新双语使用同一 rows 清单：所有源文字 retain；以完整语义单元 additions 新建目标 MText；已有双语保留但必须有完整配对证据。独立 additions 收据、来源覆盖、原文与非文字几何不变、实际字号/区域/文本重叠核验。
- 新技能继续由当前模型直接翻译，并按图选择/构建原生工具；不引入另一个翻译 API 或旧流水线。确定性的任务绑定、契约校验、保存后验证及交付使用小型共享 Python 工具。
- 最终仅交付带版本号 DWG；没有实际视觉证据不得通过验收。

## 实施顺序
1. 只读旧入口基线；编写能阻止错误模式、漏覆盖、空双语、伪配对和旧收据的失败测试。
2. 按原包覆盖入口及两份共用参考；编写新双语操作、契约与示例。
3. 实现共享任务/验证工具；删除旧活动资源，安装采用清单覆盖同步，移除残留。
4. 执行契约测试及从空白 DWG 新建的原生替换/双语回归，重新打开验证，检查截图。
5. 独立执行者复测路由及质量约束；修正实际发现的问题后核验安装哈希。

## 验证边界
新 fixture 回归是新工具/契约的功能验证，不宣称已经对所有真实图纸做整图双语验收。
